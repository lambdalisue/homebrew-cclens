# homebrew-cclens

Homebrew tap for [`cclens`](https://github.com/lambdalisue/cclens) — a lens onto
your Claude Code usage.

```sh
brew install lambdalisue/cclens/cclens
```

`Formula/cclens.rb` is generated: the cclens release workflow rewrites it on
every `vX.Y.Z` tag to point at that release's prebuilt archives (macOS and Linux,
x86_64 and arm64). Do not edit it by hand — edit the workflow instead.
